# ElectroCalc Web - Laboratorium Virtual Teknik Elektro

Aplikasi web utilitas kalkulator teknik elektro sederhana untuk membantu perhitungan komponen dasar:
1. **Kalkulator Kode Warna Resistor (4 Pita)**: Menghitung nilai resistansi dan toleransi berdasarkan kode warna.
2. **Kalkulator Hukum Ohm & Daya Listrik**: Menghitung Tegangan (V), Arus (I), Hambatan (R), dan Daya (P).
3. **Riwayat Perhitungan (History Log)**: Menyimpan histori perhitungan sesi pengguna.
